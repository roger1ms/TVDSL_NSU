# HW3. Семантический анализ и типы

В данном модуле реализован семантический анализатор для языка Funny.
Анализатор принимает на вход AST, построенный в HW2, и проверяет корректность имен и типов.

## Поддерживаемые типы

Анализатор оперирует следующими типами:
- `int` - целое число.
- `int[]` - массив целых чисел.
- `bool` - логический тип.
- `FunctionType` - тип для функций, хранящий список входных параметров и возвращаемых значений.

## Таблицы символов и области видимости

Для проверки имен используется `SymbolTable`, реализованная как **стек областей видимости** (Scopes).
- **Глобальная область**: хранит имена и сигнатуры всех функций.
- **Локальные области**: создаются при входе в тело функции и при входе в любой блок `{}`. При выходе из блока область уничтожается, что гарантирует изоляцию переменных (переменные из одного блока не видны в другом, а переменные из одной функции не видны в другой).

## Проверяемые правила

1. **Объявления и дубликаты**: запрещено объявлять две переменные с одним именем в одной области видимости (параметры, возвраты, `uses`). Также запрещено повторное объявление функций.
2. **Использование имен**: любая используемая переменная или функция должна быть объявлена до её использования (для функций - в пределах всего модуля благодаря первому проходу).
3. **Арифметика**: операторы `+`, `-`, `*`, `/` применимы только к `int`. Результат - `int`.
4. **Сравнения**: операторы `==`, `!=`, `<`, `>`, `<=`, `>=` применимы только к `int`. Результат - `bool`.
5. **Условия**: условия в `if`, `while`, а также `requires` и `ensures` должны иметь тип `bool`.
6. **Массивы**:
    - Индекс при доступе `a[i]` должен быть `int`.
    - Индексировать можно только переменные типа `int[]`. Результат - `int`.
7. **Вызовы функций**: проверяется существование функции, совпадение количества аргументов и их типов с параметрами функции.
8. **Присваивание**: тип левой части (переменная или элемент массива) должен строго совпадать с типом правой части.

## Аннотированный AST
Каждый узел выражения (`BinOp`, `Compare`, `Ident`, `Index`, `Call` и т.д.) хранит вычисленный тип. Это можно увидеть при выводе дерева в консоль (после семантического анализа).
## Ограничения

- Позиции токенов в семантических ошибках не выводятся (для упрощения), но сообщения содержат понятное описание.
- Нет перегрузки функций и неявных приведений типов.
